Check claims in an article

Paste an article URL, or upload a .md / .txt file. A link is fetched into markdown first, then an agent extracts claims, classifies them, looks up sources, and badges each claim: supported, contradicted, misleading, unverifiable, or opinion. Misleading is for a real number with a dropped caveat (the METR demo). You review every step, can override a badge into the error log, and can export annotated HTML or PDF. There is no article-level fake-news stamp.
